# Taverna Meltemi (demo)

Φανταστική οικογενειακή ταβέρνα στην Καβάλα με δίγλωσσο μενού και κρατήσεις τραπεζιών. Αυτόνομη εφαρμογή Vue 3, TypeScript, Tailwind, vue-i18n και vue-router, με προεπιλεγμένη γλώσσα τα ελληνικά.

```bash
yarn install --frozen-lockfile
yarn dev        # http://localhost:8992
yarn test       # Vitest
yarn build      # vue-tsc και Vite
```

## Τι περιλαμβάνει

- Αρχική με σύντομη φόρμα αναζήτησης τραπεζιού και τρία πιάτα της ταβέρνας.
- Μενού 24 πιάτων και ποτών σε επτά κατηγορίες, με συνδυαστικά διατροφικά φίλτρα και σημείωση αλλεργιογόνων.
- Κράτηση με έλεγχο διαθεσιμότητας στο submit, κωδικό και προεπισκόπηση μηνύματος.
- Διαχείριση στο `/admin` με κωδικό `demo`, κρατήσεις ανά ημέρα, πληρότητα επτά ημερών, ένδειξη «Κάθισε», ακύρωση και επαναφορά.

## Κανόνες κρατήσεων

- Οι αφίξεις γίνονται ανά 30 λεπτά, από τις 13:00 έως και τις 22:30, σε ώρα Καβάλας. Η κράτηση δεσμεύει θέσεις για 90 λεπτά. Η τελευταία άφιξη στις 22:30 δεσμεύει θέσεις έως τα μεσάνυχτα, ενώ το αναγραφόμενο ωράριο είναι 13:00–23:30.
- Η διαθεσιμότητα υπολογίζεται με βάση τις 56 θέσεις και τη μέγιστη ταυτόχρονη χρήση τους μέσα στο 90λεπτο. Η χωρητικότητα προέρχεται από τέσσερα τραπέζια των δύο, έξι των τεσσάρων και τέσσερα των έξι. Το demo χρησιμοποιεί κοινό όριο θέσεων.
- Η πρώτη επίσκεψη και η επαναφορά δημιουργούν δοκιμαστικές κρατήσεις για επτά ημέρες από σήμερα, με γεμάτες βραδινές ώρες. Για να δεις ένα γεμάτο παράθυρο οποιαδήποτε ώρα της ημέρας, διάλεξε την αυριανή ημερομηνία. Η ώρα 20:30 δεν εμφανίζεται μέχρι να ελευθερωθούν θέσεις.
- Η επαναφορά διαγράφει τις κρατήσεις που προστέθηκαν στον ίδιο browser και δημιουργεί νέο δείγμα με βάση τη σημερινή ημερομηνία.

## Δομή

```text
src/lib/reservations.ts  καθαρή λογική για ώρες, θέσεις και επικύρωση
src/lib/store.ts         localStorage, δοκιμαστικά δεδομένα και ενημέρωση κρατήσεων
src/data/menu.ts         κατηγορίες, πιάτα, τιμές και μεταφράσεις
src/i18n.ts              κείμενα διεπαφής EL/EN
src/views/              Αρχική, Μενού, Κράτηση, Επιβεβαίωση, Διαχείριση
```

## Φιλοξενία και πραγματική χρήση

Για static hosting όρισε root directory το `demos/taverna-meltemi`, build command το `yarn build` και output directory το `dist`. Ρύθμισε fallback στο `index.html` για τα routes του Vue Router, ώστε να ανοίγουν απευθείας το `/admin` και οι επιβεβαιώσεις. Σε υποφάκελο χρησιμοποίησε `VITE_BASE=/demos/taverna-meltemi/` κατά το build.

Τα δεδομένα παραμένουν στο `localStorage` του browser. Το μήνυμα επιβεβαίωσης είναι προεπισκόπηση και ο κωδικός διαχείρισης προορίζεται για επίδειξη. Μια πραγματική εγκατάσταση χρειάζεται API, βάση δεδομένων, έλεγχο διαθεσιμότητας στον server, ταυτοποίηση διαχειριστή και υπηρεσία αποστολής μηνυμάτων. Τα SVG placeholders μπορούν να αντικατασταθούν από φωτογραφίες του χώρου και των πιάτων.
